# Итоговая проверка от 24 ноября 2026 года

Финальный прогон выполнен на отдельном стенде Docker Compose с чистыми томами. Docker Desktop предоставлял 2 vCPU и 5,76 ГиБ памяти. Интеграционные тесты запускались в Linux с Python 3.12.16, отдельной пустой PostgreSQL 16 и Redis 7.

| Проверка | Результат |
| --- | --- |
| Docker и миграции | Образ API собрался, сервисы стартовали. Alembic применил `0001` и `0002` к пустой базе. `alembic check` не обнаружил расхождений с ORM. |
| Данные | `small` с `seed=42` создал 1 000 пользователей, 20 категорий, 100 товаров, 10 000 заказов, 28 448 позиций, 10 000 платежей, 50 000 событий и 20 000 записей истории. Повторный запуск вернул `action: reused`. Все адреса пользователей имеют домен `example.test`. |
| Baseline и Optimized | Предварительная проверка Locust подтвердила совпадение JSON по восьми операциям. В пробном прогоне каждый вариант обработал 16 запросов без ошибок. При `LAB_MODE=false` Baseline вернул 404, Optimized и проверка готовности — 200. |
| Redis и мониторинг | Два одинаковых запроса вернули `MISS` и `HIT` с тем же JSON. Все три цели Prometheus были доступны. PostgreSQL загрузил `pg_stat_statements` версии 1.10, `pg_up` равен 1. Grafana загрузила 10 панелей. Чтение системных метрик на `/metrics` вынесено из цикла событий FastAPI. |
| pytest и Ruff | В Linux прошли 117 тестов, покрытие строк `app` составило 91,35% при пороге 75%. Ruff проверил код и форматирование. |
| Отчёт и диаграммы | Повторная генерация дала те же 52 записи и побайтно совпавшие шесть PNG. Mermaid CLI отобразил все четыре диаграммы. |
| GitHub Actions | Workflow проверен `actionlint`. Миграции, тесты с порогом coverage и сборка Docker проверены локально. Выполнение workflow на GitHub ещё предстоит. |
