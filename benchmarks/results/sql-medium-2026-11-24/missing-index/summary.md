# Поиск пользователей

Индекс по `lower(city)` сокращает число строк для проверки статуса. Сортировка по ID сохраняется.

Порядок и значения строк совпали. Число строк в результате — 12. Медиана SQL-времени за 5 повторов составила 3.097 мс до изменения и 0.809 мс после. Число `SELECT` на операцию до изменения — 1, после — 1.

В [плане до изменения](explain_before.json) наблюдались Limit, Seq Scan (users), Sort.

В [плане после изменения](explain_after.json) наблюдались Bitmap Heap Scan (users), Bitmap Index Scan (lab_exp_users_city), Limit, Sort.
