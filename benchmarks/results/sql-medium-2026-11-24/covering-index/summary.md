# Покрывающий индекс позиций

Ключ B-tree остаётся одинаковым. `INCLUDE` добавляет колонки ответа. `VACUUM` перед прогоном делает страницы неизменяемого набора доступными для чтения по карте видимости.

Порядок и значения строк совпали. Число строк в результате — 1395. Медиана SQL-времени за 5 повторов составила 0.574 мс до изменения и 0.726 мс после. Число `SELECT` на операцию до изменения — 1, после — 1.

В [плане до изменения](explain_before.json) наблюдались Index Scan (lab_exp_items).

В [плане после изменения](explain_after.json) наблюдались Index Only Scan (lab_exp_items).
